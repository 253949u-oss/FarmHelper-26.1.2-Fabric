# FarmHelper 26.2 - Fabric

A FarmHelper macro for Minecraft 26.2 using Fabric Loom 1.8+

## Project Details

- **Minecraft Version**: 26.2
- **Loader**: Fabric
- **Fabric API Version**: 0.152.1+26.2
- **Yarn Mappings**: 26.2+build.1
- **Fabric Loader**: 0.19.3
- **Mod Version**: 3.0.0-fabric

## Description

FarmHelper macro for Minecraft 26.2 Fabric - Ported from 1.8.9 Forge with modern Fabric Loom 1.8+

## Building

This project uses Gradle. To build:

```bash
./gradlew build
```

The built JAR will be available in `build/libs/`

## Installation

1. Install Fabric Loader 0.19.3 for Minecraft 26.2
2. Place the built JAR in your `mods` folder
3. Ensure Fabric API 0.152.1+26.2 or later is installed
